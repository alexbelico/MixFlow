# Contributing to MixFlow

Gracias por tu interés en contribuir.

## Cómo contribuir

1. Fork el repositorio.
2. Crea una rama para tu feature o fix (`git checkout -b feature/nombre`).
3. Haz tus cambios.
4. Asegúrate de que el audio se comporta correctamente (seeking, stop al cambiar de vista, etc.).
5. Abre un Pull Request describiendo claramente el cambio.

## Áreas prioritarias

- Estabilidad del player de STEMS
- Bugs de reproducción de audio
- Mejoras de UI / waveform
- Documentación y tests de procesamiento local

## Código de conducta

Sé respetuoso. Este es un proyecto mantenido de forma individual.

## Reportar issues

Incluye:
- Pasos para reproducir
- Sistema operativo
- Qué esperabas vs qué ocurrió
- Archivos de audio de ejemplo si es posible (sin material sensible)
