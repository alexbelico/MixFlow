# MixFlow

**Herramienta local open source de mezcla y mastering de audio.**

Procesa stems, limpia tracks (incluyendo remoción de watermarks de alta frecuencia), visualiza waveforms y exporta a WAV. Todo corre en tu máquina. Sin nube.

Creado y mantenido por Hernan Bella Chozet (Alex).

## Características

- Player de STEMS con seeking
- Visualización de waveform
- UI oscura con acentos rojo oscuro
- Tipografía Bebas para branding
- Procesamiento local de audio
- Exportación a WAV
- Limpieza de acapellas / remoción de artefactos de alta frecuencia
